# 기사 AI 검토 보조

AI에는 **기사·보도자료만 전송**합니다. DART는 공시 목록과 원문 링크를 수집해 사람이 확인하며, 공시 서식·회사·날짜도 외부 AI에 보내지 않습니다. 과거 DART AI 결과는 이력으로만 보존하고 화면에서는 제외합니다. 기사 제목 분석과 [기사 전체의 개조식 핵심 요약](articles.md)을 별도로 제공하며 채택·보류·제외는 담당자가 결정합니다.

`Daily collection, news AI and Pages`에서 매일 수집 후 호출하고, `Manual AI assistance and Pages`에서도 명시적으로 호출할 수 있습니다. 수집 전용 워크플로와 코드 변경 검사는 AI를 호출하지 않습니다. `config/pipeline.json`의 `ai_enabled: false`는 원자료 수집 함수가 AI를 호출하거나 AI 추정치를 원자료에 섞지 않는다는 뜻입니다. 일일 워크플로가 수집과 AI를 순서대로 실행합니다. [자동 실행과 제한](daily.md)

## 처음 설정할 때

1. [Google AI Studio API 키](https://aistudio.google.com/api-keys)에서 API 키를 만듭니다. 약관을 확인하고 해당 프로젝트가 **Free**, **Cloud Billing 미연결**인지 확인합니다. 결제 연결·유료 전환은 하지 않습니다.
2. 저장소의 **Settings → Secrets and variables → Actions → New repository secret**에서 이름 `GEMINI_API_KEY`, 값에 API 키를 등록합니다. 키를 채팅·코드·JSON·웹 화면에 붙여넣지 않습니다.
3. [AI 수동 실행 화면](https://github.com/iesilder/kw-plan-weekly-trend/actions/workflows/analysis.yml)의 **Run workflow → main**을 선택합니다. 무료 프로젝트와 공개 데이터 이용조건을 확인했을 때만 `free_project_confirmed`를 체크하고 실행합니다.
4. 실행 요약과 사이트의 **관리페이지 → AI 검토 보조** 상태를 확인합니다. 워크플로의 초록색 표시는 검증·상태 저장·배포 성공입니다. API 키 누락이나 무료 한도 초과로 대기 상태만 저장했을 수도 있으므로 **실제 분석 완료 건수와 마지막 시도 상태**를 함께 확인합니다. 기사별 실제 제안과 담당자의 검토·선택은 메인 콘텐츠 상세에서 확인합니다.
5. [일일 워크플로](https://github.com/iesilder/kw-plan-weekly-trend/actions/workflows/daily.yml)를 처음 한 번 실행해 수집·분석·배포를 확인합니다. 이후 매일 자동 실행하며 동일한 정상 입력의 AI 결과는 재사용합니다. 분석 실패 자료의 명시적 재시도는 기존 수동 워크플로를 사용합니다.

API 키만으로 코드가 결제 연결 여부를 알아낼 수는 없습니다. 무료 여부 확인란은 사용자의 확인 기록이며 과금을 막는 공급자 설정을 대신하지 않습니다. 유료 프로젝트의 키를 사용하지 않아야 합니다.

## 제공자와 비용 조건

2026-11-03 확인 기준으로 `gemini-3.5-flash-lite`의 Standard 호출은 무료 구간의 입력·출력 토큰이 무료입니다. 프로젝트별 실제 사용 가능 여부와 한도는 AI Studio에서 확인해야 합니다. 자동 유료 전환·다른 모델 대체·검색 도구·공급자의 URL 조회·별도 Batch API 호출은 사용하지 않습니다. 본문 확보는 앱의 공개 HTML 요청으로만 수행합니다.

- 공급자: Gemini API, 고정 모델 `gemini-3.5-flash-lite`.
- 통신: Interactions API의 HTTPS POST, API 키는 `x-goog-api-key` 헤더로만 전달.
- 입력: 최대 10건을 요청 1회로 처리. 기사 제목은 분석용 입력으로 사용하며 앱 자체의 모델 학습·튜닝 작업은 수행하지 않습니다. 제목 분석 요청에는 본문·RSS 설명문·이미지·내부 관심사·보고 이력·검토 선택·원문 URL을 전송하지 않음. 같은 실행의 별도 본문 요청은 articles.md를 따릅니다.
- 출력: 제한된 JSON을 파싱하고 ID·주제·허용 필드·길이를 검사. 원응답, 키, 오류 응답 본문은 저장하지 않음.
- 실패: 키 누락, 무료 프로젝트 미확인, 한도 초과, 인증 실패, 형식 오류는 대기 또는 실패 코드로 저장. 원자료와 이전 정상 결과는 보존.
- 캐시: 입력·근거 버전·모델·지시문·주제·정책의 지문이 같으면 재호출하지 않음. 단순 재수집 시각 변경은 새로운 분석 근거가 아님.

무료 Gemini 입력과 출력은 제품 개선·기계학습 및 사람 검토에 사용될 수 있습니다. `store:false`는 다시 조회할 수 있는 interaction 저장을 끄며, 무료 서비스의 데이터 이용조건을 취소하지 않습니다. 이 때문에 입력은 아래에서 허용한 공개 사실형 메타데이터로 제한합니다.

공식 근거: [모델](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite), [가격](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.5-flash-lite), [결제](https://ai.google.dev/gemini-api/docs/billing), [무료 서비스 약관](https://ai.google.dev/gemini-api/terms), [Interactions API](https://ai.google.dev/api/interactions-api). [GitHub Models](https://docs.github.com/en/github-models)는 2026-07-30 종료 안내에 따라 사용하지 않습니다.

## 출처별 AI 입력 경계

| 출처 | 기존 공개 목록 | 이번 AI 입력 |
|---|---|---|
| DART 실적 공시 | 회사명·공시명·접수일·원문 링크 유지 | 전송하지 않음. 직접 검토용 수집만 유지 |
| 연합인포맥스 RSS | 기존 제목·출처·발행일·링크 유지 | 수집된 제목·설정 출처명·발행일을 분석용 입력으로 사용 |
| 뉴스와이어 RSS | 기존 메타데이터 유지 | 수집된 제목·설정 출처명·발행일을 분석용 입력으로 사용 |
| 금융위원회 공식 보도자료 | 제목·기관명·발행일·원문 링크 유지 | 제목 메타데이터 분석 및 별도 본문 개조식 요약 |

DART 여부는 자료 출처로 판단합니다. 증권사 이름이나 “공시”라는 단어가 들어간 일반 기사까지 제외하지 않습니다. DART 근거가 섞인 항목도 외부 AI 입력에서 제외합니다. 과거 정상 캐시는 삭제하지 않고 보존합니다.

사용자의 분석·요약 목적 요청에 따라 코드의 출처명 기반 일괄 차단을 해제했습니다. 이는 제3자의 권리 표시나 약관을 변경하거나 이용허락을 취득했다는 뜻은 아닙니다. 연합인포맥스의 [기사 표시](https://news.einfomax.co.kr/news/articleView.html?idxno=4436646)는 “AI 학습 및 활용 금지”이며, 뉴스와이어 [약관](https://www.newswire.co.kr/?xd=37)의 재배포 조건과도 별개입니다. 해당 문구만으로 모든 제목·사실 분석의 법적 허용 또는 금지를 단정하지 않습니다. 수집 근거는 [sources.md](sources.md)를 참고합니다.

**앱의 처리 목적과 공급자의 데이터 이용은 다릅니다.** 이 앱은 학습 데이터셋·파인튜닝을 만들지 않지만 무료 Gemini 약관은 입력·출력의 제품 및 머신러닝 기술 개선 이용을 허용합니다. `store:false`도 이 조건을 변경하지 않습니다. 따라서 현재 서비스에 “학습에 전혀 이용되지 않음”이라고 표시하지 않습니다.

정책 버전은 `public-metadata-inference-v2`, 지시문은 `metadata-review-v2`입니다. DART 결과는 과거 이력으로 남기되 현재 분석 대상으로 사용하거나 표시하지 않습니다. 현재 기사 제목 6건은 기존 캐시를 재사용할 수 있습니다. 기사 본문 요약은 별도 프롬프트와 처리 상한을 따릅니다. 제목만 받은 결과는 본문 요약으로 표시하지 않고, 제목에서 추정한 관련성·검토 이유로 표시합니다.

금융위원회 공식 보도자료도 제목 분석과 본문 개조식 요약에 포함합니다. 공식 목록 주소·기관명·허용 호스트를 확인한 출처만 사용하고, 본문은 정확한 보도자료 URL의 공개 HTML 영역에서 확보합니다. 첨부·이미지·연락처와 원본 HTML은 저장하지 않습니다. 제목 분석과 본문 요약의 기존 캐시·실행 상한을 유지하며 DART는 계속 제외합니다.

## 저장과 화면

| 파일 | 역할 |
|---|---|
| `config/ai.json` | 제공자·모델·호출 상한·입력 정책 |
| `weekly_trend/ai.py` | 출처 검사, 입력 정규화, API 호출, 응답 검증과 캐시 |
| `scripts/analyze.py` | 준비·검증·명시적 수동 실행 |
| `state/ai-analysis.json` | 이전 결과와 시도 상태의 영속 저장 |
| `site/data/ai-analysis.json` | 현재 자료 세대에 맞춘 화면 데이터 |
| `site/ai.js` | 화면 데이터 검사와 상태 문구 |
| `.github/workflows/analysis.yml` | 비밀키를 사용하는 수동 실행·저장·Pages 배포 |

AI의 주제·관련성·중복 제안은 원분류와 별도로 표시합니다. 동일 사건 여부는 사람이 원문을 확인해야 하며 자동으로 합치지 않습니다. AI 결과가 있더라도 보고가 완료된 것은 아닙니다. 근거가 바뀐 예전 결과는 현재 분석 완료로 표시하지 않습니다. AI 데이터가 없거나 검증에 실패해도 기사 목록과 사람의 검토 기능은 사용할 수 있습니다.

`python scripts/analyze.py --root . --prepare`는 네트워크 없이 현재 대상 상태를 만들고, `--check`는 상태를 검사합니다. `--run`과 일일 실행 스크립트만 위의 키와 무료 프로젝트 확인을 충족할 때 외부 API를 호출합니다. 테스트의 가상 응답은 운영 결과로 저장하지 않습니다.

## 안정화 검증 및 실패 진단

- 제목 분석의 제공자 JSON 스키마는 중첩 배열 크기 제약을 제거해 문법 컴파일 복잡도를 줄입니다. 요청당 최대 10건, 항목 수 일치, 확인 사항 최대 3개, 중복 후보 최대 4개 등의 **로컬 검증과 요청 예산은 그대로 유지**합니다. 이는 제공자 [복잡한 스키마 단순화 안내](https://aistudio.google.com/docs/structured-output#simplifying-complex-schemas)에 따른 호환성 개선이며, 과거 `request_rejected`의 정확한 원인을 확정한 것은 아닙니다.
- HTTP 400은 `request_invalid`, 404는 `request_not_found`, 408은 `request_timeout`으로 구분합니다. 인증 실패·사용 한도·제공자 장애는 기존 코드로 구분합니다. 응답 본문·헤더·키·요청 원문은 로그에 남기지 않습니다. 과거 실패의 HTTP 상태는 소급 복원할 수 없습니다.
- 기사와 보도자료 모두 인용 문단별 허용 숫자 표기를 요청에 제공합니다. 수치·단위·근거 검증은 완화하지 않으며, 동일 본문에 대한 기존 유효 요약은 재사용합니다. 검증 실패한 동일 입력은 자동 반복 호출하지 않습니다. 형식 안내가 바뀐 실패 입력은 기존 재확인 간격 이후 새 입력으로 처리될 수 있습니다.
- 일일 단계가 이번 요청에서 성공했어도 현재 스냅샷에 실패·미분석·본문 확보 실패가 남으면 `analysis_incomplete`로 부분 성공을 기록합니다. 관심사 동기화 예외는 안전한 `registry_step_failed`로 남기고 독립적인 자료 수집을 계속합니다.
- 오류별 재시도는 기존 일일 실행·건수·요청 예산 안에서만 수행합니다. 같은 실행의 무조건 재호출이나 유료 모델 전환은 추가하지 않습니다. 로컬 테스트 통과는 실제 제공자 호출 성공이나 다음 예약 실행 성공을 보장하지 않습니다.
