# 뉴스 분류 기준과 수정 위치

주제는 인터넷에서 자동 발견하지 않습니다. 사람이 정한 설정을 읽고, 공개 RSS에서 받은 **제목**의 대상·주제·변화 표현과 대조합니다. AI 호출, 본문 수집, 검색 API는 사용하지 않습니다.

## 설정 파일

| 수정할 내용 | 파일 |
|---|---|
| 주제 이름·활성 상태 | `config/topics.json` |
| 뉴스 관찰 회사·명칭 | `config/companies.json` |
| 뉴스 주제·변화 키워드, 태그, 단계, 관련 그룹·업권 범위 | `config/classification_rules.json` |
| 실제로 요청하는 DART 목록·RSS 주소 | `config/sources.json` |
| 제목에 설정을 적용하는 판단 로직 | `weekly_trend/classification.py` |
| 수집 결과를 분류·저장·화면 데이터로 연결 | `weekly_trend/live_pipeline.py` |

## 5개 주제

| ID | 표시 이름 | 포함하는 변화 |
|---|---|---|
| performance | 실적·자본·주주정책 | 실적 발표, 자본확충, 증자·RCPS, 지분 확대, 배당·주주환원 |
| digital | 신사업·상품·고객전략 | 새로운 사업·상품군·서비스 진입, 고객군·채널 확대, 신규 사업의 성장 성과 |
| expansion | 제휴·인수·해외사업 | MOU·전략적 제휴, 인수·지분투자, 해외법인·사무소 설립, 해외 진출 |
| strategy | 조직·경영전략 | 전담 조직 신설, 사업부 재편, AX 조직개편, 중장기 경영 방향 |
| risk | 정책·인허가·리스크 | 사업 인허가·시장 인프라 승인, 법령·정책·유권해석, 중대한 제재·사고·장애 |

기존 ID는 자료 연결을 위해 유지하며 표시 이름과 판단 규칙을 바꿉니다. 주분류는 하나이고 AI·디지털자산 등 보조 태그는 복수입니다. 예를 들어 가상의 ‘증권사 AI 상담 서비스 출시’는 신사업 주제와 AI 태그, ‘증권사 AI 전담 조직 신설’은 조직 주제와 AI 태그로 구분합니다.

## 포함 여부와 단계

뉴스는 관찰 회사 또는 관련 금융그룹·증권업권 문맥, 주제, 사업·정책 변화가 제목에서 확인될 때 포함합니다. 회사명이 없는 공통 정책도 대상이 될 수 있지만, 일반 외부기업 뉴스나 가상자산 시황 전체를 수집하지 않습니다. 단순 시황·종목 추천·고객 행사·수수료 이벤트·통상적인 개별 상품 홍보는 보통 제외합니다.

검토·추진·협약·신청·심사·인가·출시·성과 같은 단계는 제목의 표현에 따른 분류입니다. 검토를 실행으로, 인가 예고를 인가 완료로 바꾸지 않습니다. 실제 계약 내용이나 사업 성과를 원문 검증한 분석은 아니므로 원문 확인이 필요합니다.

DART는 별도의 `earnings_form()` 허용 목록을 적용합니다. 기사 범위가 넓어져도 임원 지분·계열 거래·실적 발표 예고 공시는 포함하지 않습니다. 사업·반기·분기·감사보고서 및 잠정·실제 실적 공시의 제목과 링크만 수집합니다.

## 규칙 변경과 한계

설정 변경 뒤 수동 수집을 실행하면 기존 자료도 다시 분류합니다. 분류만 바뀌었다고 원문 자료의 새 버전을 만들지 않습니다. 뉴스 수집 정책이 바뀌면 최근 30일을 다시 확인하지만, RSS에 남아 있는 항목만 읽으므로 과거 전체 기사를 소급 검색하지는 못합니다.

규칙 내용·회사 명칭/별칭/활성 상태·주제 이름·출처 범위를 함께 비교해 변경 여부를 계산합니다. 규칙 파일의 `version` 문자열을 그대로 두고 키워드만 수정해도 다음 실행에서 변경을 감지합니다. `topics.json`의 이름은 화면 표시에 쓰이며 수집 단어를 바꾸려면 `classification_rules.json`의 `topic_keywords`와 해당 변화·대상 규칙을 수정합니다.

본문에만 나타나는 회사·주제·변화나 규칙에 없는 표현은 놓칠 수 있습니다. 태그와 진행 단계는 제목 규칙의 결과이며 최근 관심 주제·중요도·기보고 여부를 뜻하지 않습니다. 보고 기준을 설계하기 위해 제공된 내부 자료는 이 공개 저장소의 기사, 보고 이력, 테스트 원문으로 게시하지 않습니다.
