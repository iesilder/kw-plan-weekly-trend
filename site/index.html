선택 내용을 GitHub에 저장

현재 선택은 이 브라우저의 임시 저장입니다. 아래 절차를 마치면 다른 기기에서도 저장한 선택을 불러올 수 있습니다.

  1. 아래 저장 내용을 복사합니다.
  2. GitHub 저장 화면 열기 ↗를 누릅니다.
  3. Run workflow에서 main을 선택하고 review_patch 칸에 붙여넣어 실행합니다.
  4. 실행과 Pages 배포가 끝나면 이 사이트의 자료 다시 불러오기를 누릅니다.

자료 ID와 선택 상태가 공개 저장소에 기록됩니다. 계정 토큰을 입력할 필요가 없습니다. 기사 수집이나 실제 보고 완료 처리는 실행하지 않습니다.
